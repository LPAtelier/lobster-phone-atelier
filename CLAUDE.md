# Lobster Phone Atelier

Design-to-product automation pipeline. The designer drops files; the system handles the rest.

## Concept

1. **Design input** — drop a PNG/SVG + mood board reference images
2. **Mockup generation** — place design on real products (t-shirt, bandana, towel, etc.) via print-on-demand API
3. **Lifestyle photography** — AI-generated styled photos matching the brand aesthetic
4. **Auto-publish** — push products to Shopify storefront with Printful/Contrado fulfillment

## Owner role

Designer only. No pipeline steps, no manual config per design. Drop file → done.

## Future

Support private client storefronts with unique brand pages/links.
