Design-to-product automation pipeline for a print-on-demand storefront under the brand "Lobster Phone Atelier."

**Why:** Owner is a designer only — drops design files and reference images; automation handles everything else.

**Pipeline stages:**
1. Design input (PNG/SVG files + mood board references)
2. Product mockup generation on real products (t-shirt, bandana, towel, etc.)
3. AI lifestyle photography generation matching brand aesthetic
4. Auto-publish to Shopify storefront (Shopify + Printful/Contrado for fulfillment)

**Future:** Support private client storefronts with unique brand pages/links.

**How to apply:** Keep the user out of technical pipeline steps. Optimize for "drop file, done." Evaluate API choices by how little manual config they require per new design.
